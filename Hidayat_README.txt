------------------------------------------------------------------------
Software Chalane Ka Tariqa (How to Run):
------------------------------------------------------------------------
Method 1 (Executable / Standalone App):
1. Folder me mojood "Create_Desktop_Shortcut.bat" par double click karein
   (ye aap ke desktop par "Smart POS" ka shortcut bana dega).
2. Ya seedha "Smart_POS.exe" par double click kar ke software open karein.

Method 2 (Source Code / Python):
1. Terminal / CMD me dependencies install karein:
   pip install -r requirements.txt
2. Software start karein:
   python app.py
3. Browser me open karein:
   http://127.0.0.1:5000
